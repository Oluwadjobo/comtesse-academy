# Banque de questions — première proposition

- `questions-initiales.json` : 18 questions à choix unique réparties dans les six modules.
- Toutes les questions ont le statut `validationStatus: proposed`.
- `criticalProposed: true` signifie que la criticité est proposée et n'est pas encore homologuée.
- Les consignes métier, en particulier la chaîne du froid et les procédures de tournée, doivent être confirmées par les responsables COMTESSE avant publication.
- Les références de source sont indiquées par question. Les questions portant sur les prix sont explicitement fondées sur la nécessité de consulter la liste de prix en vigueur et non sur un prix inventé.
- Ce fichier constitue une banque pilote, pas encore une banque suffisamment volumineuse pour garantir des examens distincts de façon répétée.
