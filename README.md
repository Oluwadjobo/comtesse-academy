# COMTESSE Academy

Plateforme de formation interactive destinée aux nouveaux commerciaux Yaourt de COMTESSE.

## Objectifs
- Formation autonome sur ordinateur et téléphone.
- Six modules pédagogiques.
- Banque de questions avec variantes.
- Examen de 20 questions, seuil de réussite de 80 %.
- Réussite obligatoire de toutes les questions critiques.
- Attestation PDF et vérification en ligne.
